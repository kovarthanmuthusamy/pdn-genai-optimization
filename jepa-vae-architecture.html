Module Roles

VAE — Decap Grammar Engine

Learns the "grammar" of valid decap placements. Compresses sparse, discrete layouts (part numbers, values, slot positions) into a smooth, KL-regularized continuous latent space z_a.

Improvement: replace the standard Gaussian decoder with a Gumbel-Softmax output layer that selects from the actual parts library catalogue. Prevents physically impossible decoded values (e.g. "73.2 nF").

JEPA — Physics Surrogate Simulator

Acts as a differentiable surrogate for EM/SPICE simulation. Takes the static board geometry s_x and the decap action z_a, predicts the physical impedance outcome ŝ_y in joint embedding space.

Improvement: z_a enters the predictor via FiLM (Feature-wise Linear Modulation), not simple concatenation — because z_a modulates how the geometry should be interpreted, not just appends data.

Optimization Workflow

Step 1 — Encode the fixed board context

Pass the static PCB layout geometry through the frozen JEPA Context Encoder → get s_x. Computed once per board and cached. Never updated during the optimization loop.

Step 2 — Encode the target impedance profile

Pass the target impedance profile Z_target(f) through the frozen frequency-domain Impedance Encoder → get s_y_target. This is the destination in the physics embedding space.

Step 3 — Latent optimization via gradient descent

Initialize a random z_a in the VAE's prior. Then iterate:

1. Feed s_x and z_a into the JEPA Predictor (FiLM conditioned on z_a) → get ŝ_y and Ẑ(f)

2. Compute: Loss = ‖ŝ_y − s_y_target‖² + α · L_hinge(Ẑ(f)) + β · KL_Reg(z_a)

3. Backpropagate through JEPA Predictor back to z_a. The KL term keeps z_a inside the VAE's valid region.

4. Update z_a via gradient descent. Repeat until loss converges.

Step 4 — Decode to real hardware

Pass the optimized z_a* through the VAE Decoder (Gumbel-Softmax). Take the argmax at each slot to obtain the physical decap values and positions for fabrication.

Step 5 — Round-trip fidelity check

Re-encode the decoded layout → z_a'. Run one JEPA forward pass with z_a' and verify the predicted physics has not drifted significantly from ŝ_y at z_a*. If drift exceeds a threshold, trigger Stage 2.5 re-training.

Training Strategy — Three Stages

Stage 1 — Train the VAE independently

Train purely on a dataset of valid decap configurations using reconstruction loss + KL-divergence. Use a Gumbel-Softmax output layer over the parts library. Freeze all VAE weights once the decoder reliably reconstructs layouts. This is the foundation everything else depends on.

Loss: Recon + KL Input: valid decap configs Freeze on convergence
Stage 2 — Train the JEPA (VAE frozen)

Generate a dataset of (board geometry, decap layout, EM impedance profile Z(f)) triples from SPICE or EM field simulation. Pass each decap layout through the frozen VAE Encoder to obtain z_a. Train the JEPA using VICReg (variance + covariance regularization) to prevent embedding collapse.

Loss: VICReg Input: simulation triples VAE frozen
Stage 2.5 — Fine-tune decoder for physics consistency

Freeze the VAE Encoder and the entire JEPA. Fine-tune only the VAE Decoder using a physics-consistency loss: penalize any decoded layout whose re-encoded z_a' causes the JEPA to predict physics significantly different from z_a's physics. Closes the round-trip amortization gap.

Loss: Physics consistency Decoder only Encoder + JEPA frozen

Meta-pattern validated in drug discovery (Gómez-Bombarelli et al. 2018), crystal structure prediction, and differentiable NAS. The PCB domain adds the discrete parts-library constraint and frequency-domain physics — both addressed by Gumbel-Softmax output and the dedicated impedance encoder respectively.

Asymmetric Optimization: "Below Target" in Vector Space

Why a symmetric MSE loss cannot express Z_pred(f) ≤ Z_target(f) — and how to fix it

Core problem: The original loss ‖ŝ_y − s_y_target‖² is symmetric — it penalizes being 5 dB above and 5 dB below the target equally. But the physical constraint is one-sided: any frequency where Z_pred exceeds Z_target is a hard violation; being below is always acceptable. MSE in embedding space cannot express this inequality.

Why the Spaces Disagree

Left: in signal space, "below target" is a frequency-wise boundary. Right: in embedding space, the same concept is a half-plane defined by a learned compliance direction d. MSE treats both sides of d equally (circle); the actual constraint is one-sided (half-plane).

Frequency-domain view: pointwise inequality across all frequencies
Embedding space: the compliance boundary is a learned hyperplane through s_y_target

Three Approaches — Compared

ApproachHow it worksProsCons
1. Symmetric MSE only (original) ‖ŝ_y − s_y_target‖² Simple. Smooth gradients. Works near target. Equally penalizes being below (OK) and above (violation). Will overshoot.
2. Asymmetric hinge in embedding space max(0, (ŝ_y − s_y_target) · d) Works in embedding space. No extra decoder head at inference. Requires order-preserving encoder training. Direction d must be learned.
3. Hybrid: MSE + signal-space hinge (recommended) MSE for direction + ReLU hinge on decoded Ẑ(f) vs Z_target(f) Directly enforces per-frequency constraint. Interpretable. No geometry assumption. Requires a Z(f) decoder head on the JEPA predictor.

Recommended: Hybrid Loss Formulation

Attach a lightweight decoder head to the JEPA Predictor that maps ŝ_y → Ẑ(f). The full optimization loss becomes:

# Full optimization loss (evaluated at each gradient descent step)

# 1. Embedding guidance term (smooth gradients toward target region)
L_embed = torch.norm(s_y_hat - s_y_target) ** 2

# 2. Per-frequency compliance hinge (one-sided: zero when below target)
# Z_hat: (batch, N_freq) predicted impedance from decoder head
violations_dB = torch.relu(to_dB(Z_hat) - Z_target_dB)   # shape: (batch, N_freq)
L_hinge = (violations_dB ** 2).mean(dim=-1)                # mean over frequencies

# 3. KL regularization (keep z_a inside VAE prior)
L_kl = kl_divergence(z_a, prior)

# Combined — alpha is warmed up from 0 to alpha_max over training
loss = L_embed + alpha * L_hinge + beta * L_kl

The hinge gradient is zero when the predicted impedance is already below target. The optimizer only corrects violations. MSE provides smooth guidance even when no violations are active. Use a warm-up schedule on α to prevent the hinge from dominating early when Ẑ(f) is still inaccurate.

Working in Log-Impedance (dB) Space

Always apply the hinge in log space. Engineers specify targets in dB, and a 3 dB violation is equally bad whether at 1 mΩ or 100 mΩ.

Z_hat_dB    = 20 * torch.log10(Z_hat.abs() + 1e-12)
Z_target_dB = 20 * torch.log10(Z_target_signal + 1e-12)

violations  = torch.relu(Z_hat_dB - Z_target_dB)
L_hinge     = (violations ** 2).mean(dim=-1)

Architecture Modification — Decoder Head

What to add to the JEPA Predictor
# Shapes: d = embed dim, F = num freq points
# Predictor: (s_x, z_a) → ŝ_y ∈ ℝ^d
# Z_head:    ŝ_y → Ẑ(f) ∈ ℝ^F (log-Z values)

class JEPAPredictor(nn.Module):
    def forward(self, s_x, z_a):
        s_y_hat = self.predictor(s_x, z_a)   # embedding
        Z_hat   = self.z_head(s_y_hat)        # impedance head
        return s_y_hat, Z_hat

Train Z_head jointly during Stage 2 with MSE against simulated Z(f) values. Converges quickly since ŝ_y already encodes physics.

Full optimization loop
z_a = torch.randn(latent_dim).requires_grad_(True)
opt = torch.optim.Adam([z_a], lr=1e-2)

for step in range(n_steps):
    alpha = min(1.0, step/warmup) * alpha_max

    s_y_hat, Z_hat = jepa(s_x, z_a)

    L_e = torch.norm(s_y_hat - s_y_target)**2
    L_h = (torch.relu(
             to_dB(Z_hat)-Z_target_dB)**2).mean()
    L_k = kl_reg(z_a)
    loss = L_e + alpha*L_h + beta*L_k

    opt.zero_grad(); loss.backward(); opt.step()
    with torch.no_grad():
        z_a.clamp_(-3, 3)  # keep in VAE region

The asymmetric hinge loss is the same mechanism as SVM margin objectives. Applying it in log-impedance space via a decoder head is the most direct translation of the "stay below the target envelope" engineering constraint into a differentiable optimization objective. The embedding MSE steers; the hinge enforces.
