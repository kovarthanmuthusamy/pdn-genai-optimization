# Your drafting space

`15-Ideas/` is never touched by `tools/build_vault.py`. Put chapter drafts, argument
sketches, figure plans, and supervisor feedback here, and link into the generated graph
with `[[...]]`.

A useful habit: when you assert something in a draft, link the note that carries its
evidence — [[al_exp059_gp_error_001]] for AL numbers, an experiment note for a config
value, a `30-Code/` note for an implementation detail. Unresolved links show up in the
graph as hollow nodes, which is a fast way to spot claims that have no backing yet.

See [[Claim Ledger]] for what is currently defensible and what is not.
